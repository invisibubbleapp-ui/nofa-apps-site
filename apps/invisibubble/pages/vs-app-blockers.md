Invisibubble is a timer you set yourself before each scrolling session, while app blockers and screen time limits usually restrict apps based on rules or a daily limit set in advance. Which one fits depends on whether you want a check-in you control each time, or a limit that is decided ahead of time.

All three approaches can be useful. This page describes how they differ, without ranking them.

## Three approaches

### A timer you set yourself: Invisibubble

You choose the minutes each time, before you start scrolling: 5, 10, 15, 30 minutes or a custom time. A bubble stays at the edge of the screen. When time is up, a full-screen takeover asks "I'm done" or lets you add extra time. The second extension needs a typed reason.

### App blockers

App blockers are apps that limit access to chosen apps or websites. Features differ a lot between products. Many work with schedules, daily limits or lists of blocked apps. Some make it hard to undo a block until a set time.

### Built-in screen time limits

Many Android phones include Digital Wellbeing. It lets you set a daily timer for an app. When that timer runs out, the app is paused for the rest of the day. See [Google's Digital Wellbeing help page](https://support.google.com/android/answer/9346420) for details on your phone.

## Side by side

| --- | --- | --- | --- |
| When you set the limit | Before each session | In advance, as rules | In advance, per app |

## When each one may fit

- **A timer you set yourself** may fit if you want to keep using an app, but decide in advance how long each session should be.
- **An app blocker** may fit if you want firm rules that are hard to undo in the moment.
- **A built-in daily timer** may fit if one total limit per app each day is enough for you.

Some people use more than one. Invisibubble does not change Android's own Digital Wellbeing settings.

Research on timers and other [digital self-control tools]({{article:what-scrolling-does-to-sleep-mood-focus-and-body}}#what-helps) finds modest effects, mostly in short-term studies.

## FAQ

### Is Invisibubble an app blocker?

No. Invisibubble is a timer you set yourself before you scroll. It does not lock apps. When the time is up, a full-screen takeover lets you choose "I'm done" or add extra time.

### Can I use Invisibubble with Digital Wellbeing?

Yes. Digital Wellbeing is part of Android on many phones and works separately. Invisibubble does not change its settings.

### Which is better, a timer or a blocker?

Neither is better for everyone. A timer you set yourself gives you a check-in each session. A blocker enforces rules decided in advance.
